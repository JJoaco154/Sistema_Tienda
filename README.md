# 🛒 Sistema de Tienda Online

Sistema de tienda online desarrollado en **PHP** como proyecto educativo y práctico.

El proyecto tiene como objetivo aplicar conocimientos de **PHP, programación web, manejo de bases de datos MySQL y organización del código**, desarrollando una tienda con usuarios, productos, carrito de compras y pedidos.

Aunque se trata de un proyecto educativo, el sistema cuenta con una implementación funcional de sus principales características.

---

## 📌 Sobre el proyecto

La aplicación permite simular el funcionamiento de una tienda online.

Los usuarios pueden registrarse, iniciar sesión, consultar productos, agregarlos al carrito y realizar pedidos.

Además, el sistema cuenta con una sección administrativa para gestionar diferentes aspectos de la tienda.

El proyecto fue desarrollado como práctica para aplicar los conocimientos adquiridos en programación y desarrollo web.

---

## ⚙️ Tecnologías utilizadas

- 🐘 **PHP**
- 🗄️ **MySQL**
- 🌐 **HTML**
- 🎨 **CSS**
- 🔌 Conexión PHP - MySQL
- 🧱 Programación Orientada a Objetos
- 📦 DAO para el acceso a datos

---

## ✨ Funcionalidades

### 👤 Registro de usuarios

El sistema permite crear nuevos usuarios mediante un formulario de registro.

La información de los usuarios se almacena en la base de datos.

### 🔐 Inicio de sesión

Los usuarios pueden iniciar sesión en el sistema para acceder a las funcionalidades correspondientes.

### 🛍️ Productos

El sistema permite mostrar y trabajar con los productos disponibles en la tienda.

Los productos se obtienen desde la base de datos.

### 🛒 Carrito de compras

Los usuarios pueden agregar productos al carrito y gestionar los productos seleccionados antes de realizar un pedido.

### 📦 Pedidos

El sistema permite realizar pedidos a partir de los productos seleccionados en el carrito.

Los pedidos quedan registrados para poder ser gestionados posteriormente.

### 👨‍💼 Administración

El proyecto cuenta con una sección administrativa para gestionar diferentes elementos de la tienda.

Desde esta parte se pueden realizar operaciones relacionadas con los productos y usuarios del sistema.

---
